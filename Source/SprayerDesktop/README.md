# 施药机上位机

## 运行

1. 将电脑的 USB 转 RS485 模块接到 STM32 的上位机通信总线。
2. 启动 `SprayerControl.App.exe`。软件会在后台扫描可用串口，通过 Modbus 握手自动识别并连接控制器，无需选择 COM 口或点击连接。
3. 通信固定为 Modbus RTU、38400、8N1、从站地址 1；超时会自动重试两次。
4. 填写参数后点击“应用参数”；该操作不会写入 STM32 Flash。
5. 需要保存上电默认值时，先关闭水泵，再点击“保存为上电默认值”。
6. “PWM 总开关”独立控制四组电磁阀输出；STM32 每次上电后该开关默认关闭。
7. 底部“操作日志”按时间显示中文发送、接收和错误记录，可随时清空。
8. 只有收到合法 Modbus 回传才显示“控制器已连接”。运行中断线后软件会自动重新扫描并恢复连接；不会自动重发断线时失败的操作。

## 控制关系

- 第1组：左上、右上电磁阀。
- 第2组：左中上、右中上电磁阀。
- 第3组：左中下、右中下电磁阀。
- 第4组：左下、右下电磁阀。
- PWM 固定为 10 Hz，四组起始相位依次为 0、25、50、75 ms。
- 占空比不能设为 0，允许范围由界面中的最小值和最大值限定。
- 关闭 PWM 总开关会立即停止四组输出，但保留当前占空比参数；开关状态不保存到 Flash。
- 回流比例阀目标电流可直接输入0.000–20.000 mA，由STM32第二路RS485以0–20000 µA写入电流模块。
