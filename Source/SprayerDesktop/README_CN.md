# 上位机目录说明

本目录保存上位机软件源码，用于通过 TTL 转 RS485 与 STM32 进行 Modbus RTU 通信。

当前已实现：八阀联动调节、四组独立调节、占空比上下限、PWM总开关、回流比例阀0.000~20.000 mA目标电流直设、状态显示、参数保存和带毫秒时间戳的中文操作日志。

软件启动后在后台扫描全部可用串口，通过 Modbus 握手自动识别控制器，不显示 COM 号，也不需要用户刷新或连接。收到控制器合法回传后才显示连接成功；运行中断线后自动重新扫描并恢复连接。每条指令显示回传确认、响应耗时和成功/失败计数。Windows 串口读取使用 700 ms 硬超时，控制器无响应时不会无限停在“正在发送”。
